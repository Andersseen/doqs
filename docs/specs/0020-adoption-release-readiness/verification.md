### Volt UI control comparison (AC-003)

An unmodified checkout of `7c76ef3b…` (frozen lockfile, `node-server` preset, only a `prerender.routes` list of nine host routes, no Doqs) prints `[uncaughtException] ReferenceError: MutationObserver is not defined` at `setupOrTeardownObserver` (ng-primitives `fromMutationObserver`, reached from its collapsible), prerendering completes, and 9/9 routes are written. The adoption build prints the same single occurrence, completes and writes 213 pages. The earlier "interruption" is reproducible only when the harness runs as a background job with an inherited stdin (the process then sat at 0 % CPU after the message); the harness now closes stdin. Upstream Volt UI has no prerender step of its own (Cloudflare serves it with live SSR), so the error is existing upstream SSR behavior, not an overlay or Doqs defect.

### Analog SSR status (Phase 8)

Analog 2.9.0 dev SSR against Showcase A (`vite --port 4402`), two passes, identical: `/docs/guides/localization` 200 (Doqs article), `/docs/guides/nope` 200 (empty `app-root`, `unmatched: 'continue'` leaves it to the host), `/es/docs/guides/nope` 200, `/ar/docs/nope` 200, `/docs/v/1/nope` 200 with the Doqs region rendered (the path where `DoqDocsComponent` sets `RESPONSE_INIT.status = 404`), `/` 200. `@analogjs/router@2.9.0` and `@analogjs/platform@2.9.0` contain no reference to `RESPONSE_INIT`. Showcase builds are static (no Nitro server is emitted), so the status is not testable on a production server here. No supported narrow fix exists; the limitation is documented, not simulated, and HTTP 404 is claimed only for static hosting.
